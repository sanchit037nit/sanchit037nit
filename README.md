### 📈 ARO-LSTM Pairs Trading

An algorithmic trading project combining statistical arbitrage, cointegration analysis, LSTM-based signal prediction, and an interactive financial dashboard.

**Tech Stack:** Python, TensorFlow/Keras, Pandas, NumPy, Statsmodels, Streamlit, Plotly

**Key Features**

- 📊 Cointegration analysis using Johansen tests and ADF tests
- 🧠 LSTM-based trading signal prediction
- 🐜 Ant Colony Optimization (ARO) for model optimization
- 📉 Mean-reversion signals using Z-score thresholds
- 💰 Hedge-ratio-based position sizing
- 🎛️ Interactive Streamlit controls for execution thresholds and initial capital
- 📈 Plotly visualizations for trading signals and portfolio equity curves
- 📊 Performance metrics including total return, Sharpe ratio, trade count, and maximum drawdown

### 💳 UPI Fraud Detection Using Machine Learning

A machine learning classification system for identifying potentially fraudulent UPI transactions using data preprocessing, feature engineering, class balancing, and model optimization.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Imbalanced-learn, Matplotlib, Seaborn

**Key Features**

- 🧹 Data cleaning, duplicate removal, missing-value handling, and feature engineering
- 🔄 Categorical encoding and removal of unnecessary identifier columns
- ⚖️ SMOTE-based class balancing on training data
- 🌳 Comparison of Decision Tree, Random Forest, Gradient Boosting, and XGBoost
- 🔍 Hyperparameter optimization using GridSearchCV
- 📊 Evaluation using accuracy, ROC-AUC, and F1-score
- 🎯 Reported Random Forest accuracy of 94.9%

**Reported Performance:** 94.9% accuracy; verify the evaluation setup and test-set metrics before treating this as a generalizable fraud detection result.
